Use a manual list to present a curated group of links that an editor selects and orders by hand. Editors control what appears and in what order; the list does not update automatically. For lists that populate automatically, use the [Automated list]({% link _components-advanced/automated-list.md %}).

## When to use

- you need to highlight a specific, handpicked set of links
- the list should remain stable and not change as new content is published
- the links share a common theme and can sit under a single heading
- the list is simpler than what [Feature link list]({% link _components/feature-link-list.md %}) provides – descriptions and hover icons are not needed

## When not to use

- when the list should update automatically as new content is published – use [Automated list]({% link _components-advanced/automated-list.md %}) instead
- when descriptions and directional icons are needed for each link – use [Feature link list]({% link _components/feature-link-list.md %}) instead
- when there are more than eight items – consider a page listing or card grid

## Related components

- [Feature link list]({% link _components/feature-link-list.md %}) – use when links benefit from descriptions and hover icons.
- [Automated list]({% link _components-advanced/automated-list.md %}) – use when the list should populate automatically from published content.
